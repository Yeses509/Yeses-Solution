# YESES SOLUTION — Web Design Studio

Single-file website for YESES SOLUTION web design studio.

## Deploy on Hostinger
1. In Hostinger hPanel: **Websites → Dashboard → Git** (or **Advanced → Git**).
2. Connect this GitHub repository and set the branch (e.g. `main`).
3. Set the deployment path to `public_html` (the repo root contains `index.html`).
4. Every push to the branch auto-deploys.

Alternatively upload `index.html` directly to `public_html` via **File Manager**.
