# YESES SOLUTION

Portfolio website for YESES SOLUTION, a web design studio.

- Single-page static site (`index.html`), no build step needed.
- Hash-based routing (`#/work`, `#/demo/aurora`, ...), so it works on any static host.
- Deploy: upload or Git-deploy the repository root to `public_html` on Hostinger.

Before going live, replace the placeholder email `hello@yourdomain.com` in `index.html`.
